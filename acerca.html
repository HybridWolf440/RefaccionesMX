Sobre el proyecto

AutoParts MX
¿Cómo fue construido?

Sitio web completo de comercio electrónico de refacciones automotrices desarrollado para la materia de programación web.

🎨
DISEÑO & FRONTEND
Interfaz oscura estilo automotriz construida con HTML5, CSS3 y JavaScript puro. Diseño responsivo con carrusel animado, geolocalización en tiempo real y catálogo interactivo.
⚙️
BACKEND & BASE DE DATOS
Sistema de autenticación con PHP y MySQL en servidor AwardSpace. Registro e inicio de sesión de usuarios con contraseñas encriptadas y manejo de sesiones seguro.
🔌
API & SERVICIOS
Catálogo propio en JSON con 40 refacciones reales. Geolocalización con Nominatim y OpenStreetMap. Google Analytics integrado para análisis de visitas y comportamiento.
AUTOPARTS MX

Tu distribuidora de refacciones automotrices en Ciudad Juárez. Calidad, garantía y entrega rápida.
